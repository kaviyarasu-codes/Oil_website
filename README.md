# Sundaram Oils — website

![Sundaram Oils website](docs/screenshot.webp)

Brand and product website for **Sundaram Oils**: home, about, products and contact pages with a PHP + MySQL contact form.

- **Tech:** HTML · CSS · JavaScript · PHP · MySQL
- **My role:** structure, content, mobile-first layout, on-page SEO and deployment on Hostinger
- **Status:** delivered during my internship at Aero Edge Media (the client domain has since lapsed)

## Setup
The site lives in `Oil_website/`. Copy `Oil_website/config.example.php` to `config.php`, fill in your database details, then run `setup_database.php` once. `config.php` is never committed.
